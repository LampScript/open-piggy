# preview.2：继续对齐 FlyAI CLI

2026-11-20。基线为官方 CLI 1.0.16；首版详细差异保留在 [preview.1 对比](official-cli-diff.zh-CN.md)。

**本轮从 4 类查询有真实结果，推进到 6 类；仍不宣称 8 类功能完整对齐。** 查询依旧纯 HTTP，浏览器只用于官方扫码登录。

## 日期与筛选语义

- 出发日期可用 `--dep-date` 或完整的 `--dep-date-start/end`；返程同理。固定日期与同方向范围不能混用。
- 逐个合法日期组合顺序查询。默认 `--max-date-pairs 49`，超出时在请求前拒绝，可显式调整预算；不抽样后声称查全。
- 日期组合全部完成只代表日期覆盖；机票仍受 `--limit` 候选限制，输出 `itinerariesExhaustive:false`。失败的日期不会被静默略过。
- 小时端点为0–23，包含整个边界小时；结束23包含23:59。跨午夜时段需分两次查询。起降条件作用于每个方向的当地时间。
- 总时长仍严格小于指定小时数；往返分别判断。火车往返价格上限针对两个单程起价的总和。
- 机票 `--transport-no` 保留航班白名单语义；新增 `--outbound-flights`、`--return-flights` 按顺序精确匹配，避免白名单误选。
- 排序1/3为价格降／升序；4/5为整段行程总耗时升／降序；6/7为去程出发时间升／降序；8直达优先；2保持提供方顺序，不产生自制推荐分。
- `--experimental` 不再是机票命令的必需参数，旧调用仍可保留。

## 示例

```sh
open-piggy search-flight --origin SHA --destination LAX \
  --dep-date-start 2027-02-04 --dep-date-end 2027-02-05 --back-date 2027-02-12 \
  --outbound-flights AC026,AC554 --return-flights AC551,AC025 \
  --transfer-city 温哥华 --seat-class-name economy --total-duration-hour 20 --sort-type 3 --limit 1

open-piggy search-train --origin 上海 --destination 北京 \
  --dep-date 2027-02-04 --back-date 2027-02-12 \
  --dep-hour-start 6 --dep-hour-end 6 --seat-class-name 'second class' --sort-type 3 --limit 1

open-piggy search-marriott-hotel --dest-name 上海 \
  --check-in-date 2026-12-01 --check-out-date 2026-12-02 \
  --hotel-brands 万豪 --sort price_asc --limit 3
```

## 验证与风险

酒店和万豪已有真实登录会话HTTP验收，来源及支持品牌见 [酒店证据](hotel-evidence.md)。酒店价格用官网展示字段；不把价格口径、税费或余量补成默认值。酒店上游曾出现结构不一致，当前会明确报错而非忽略未知字段。

火车跨日期和独立往返查询已通过HTTP实测；未来预售日期依旧输出不可订状态。机票新增筛选、顺序、金额单位、往返链接类型、日期完整性及异常日期响应都有回归测试。跨平台CI与本地验收分开记录。

距离正式对齐仍有明显缺口：火车中转、酒店高级过滤／海外、万豪套餐、网页AI搜索、机票规则详情。当前继续发布预览版。
